# Работа через среду

Правила находятся у владельца и выдаются общим входом `/api/environment`.
Через `knowledge.read` открой
`./rules/documents/meta/notes/environment-workflow.md` и следуй полученному
документу. Описания и схемы команд предоставляет начальный контекст среды.
