# @zavx0z/storybook

Shared development framework for repository- and package-owned Storybooks.

This repository does not own Engine, Layout, UI, Node, or MetaFor stories. Each
real repository or package owner keeps its catalog, scenarios, preview state,
lifecycle, static delivery, and acceptance. This package is intended to provide
the common Workbench, route, server, build, and evidence contracts after the
cross-repository architecture is investigated and approved.

The initial migration brief is in [MIGRATION_PROMPT.md](MIGRATION_PROMPT.md).
