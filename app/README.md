# Просмотр сценариев

App связывает код использования сущности, данные выбранного варианта
и его пункты. Подготовка данных принадлежит Archetypes, фикстура компонента —
самому компоненту, загрузка подготовленного представления — сборке Storybook.

Вверху Inspector находится один Editor с подсветкой TypeScript. Под ним
варианты образуют аккордеон: раскрытие варианта обновляет декларацию и props
общего компонента. В Display остаётся только результат, расположенный по центру
по своим фактическим границам, с сохранением авторских размеров.

Для серверной функции Inspector показывает её вызовы с фактическими аргументами.
Выбор варианта запускает его исходный тест на сервере с параметрами этого варианта.
До завершения показывается состояние выполнения; затем — результат проверок
и полные данные вызовов в редакторе JSON. Возврат к уже просмотренному варианту
выполняет новый запуск. Код серверной функции остаётся на сервере.
При быстром переключении ответ предыдущего запуска не заменяет текущий результат.

Host монтирует preview в свой semantic Document и освобождает его при уходе
со страницы сценария. Переключение варианта сохраняет экземпляр компонента.

[Исполняемые примеры](spec/scenario.spec.ts) раскрывают публичный выбор варианта,
снимки компонента и функции, уведомление подписчика и отписку.
