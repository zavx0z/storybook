# Пакетные ссылки окружения

Декларации Env ссылаются на ресурсы по имени пакета и относительному `path`.
Исполняемые модули указываются через имя пакета и `export`. Markdown и JSON
входят в `package.json#files`; дополнительный export файла не требуется.
Локальные дополнения `.agent` сохраняют относительные ссылки своей области.

Читатель `package/resources/access` находит подключённый пакет независимо от
расположения Repo. Физические пути используются внутри чтения. Фикстуры Env
подготавливают этот читатель и передают настоящие тексты в `expect`, не заменяя
документы. В декларациях и аргументах вызовов сценария Package Env нет путей
машины. Сохранённые старые ревизии и история не переписывались.

Проверены перенос dependency в другую директорию, чтение файла из `files`,
разрешение модуля через `exports` без его исполнения и отказы при выходе за
границу. Проверки типов прошли. 580 выбранных тестов прошли, включая получение
стартового контекста и документа по запросу для всех шести уровней через
контрольного ACP-исполнителя. Это не проверка разработки облачной моделью.
Нормативные сценарии затронутых новых границ сохранили общие непроверенные
пункты, нарушений автоматизированных требований не обнаружили.

В работающем Web выбранный expect «Общие правила Package» открывает исходный
Markdown. Package Env применён с ревизией `1d2373b98bd8ced3a8826a34`; полная
пересборка Web не потребовалась. Ошибка первого подключения browser bridge
для Repo и Domain устранена штатным повторным открытием/применением; код
браузерной платформы не изменялся.

## Другие найденные прямые адреса

- `meta/notes/common-agent-rules.md` Project содержит машинные Markdown-ссылки
  на Основания, архитектуру, навыки и внешние платформенные документы.
- В сырых отчётах сценариев `calls.module` и `calls.location.path` сохраняют
  физическое происхождение исполнения; это отдельный формат от декларации Env.
- В `specs/scenarios/spec/scenario.spec.ts` и других сценариях файловых читателей
  входы пока строятся через `resolve(import.meta.dir, ...)` и попадают в трассу.

Эти места отмечены отдельно и не объявляются исправленными данным изменением.

Через `storybook_check` применены Package Env, Env шести уровней, Contracts Env,
Specs Env, TypeDoc Env и Package Resources Access. Все одиннадцать итоговых
проверок завершились успешно.
