# Доставка окружения шести уровней

Project, Repo, Domain, Cluster, Container и Component проверены через настоящую
цепочку Chat Server → Session → Environment с контрольным ACP-исполнителем.
Реальная облачная модель в этом сценарии не запускается.

В каждом случае получатель сначала получает краткие промпты общей работы и своей
роли вместе с инструментами. Затем он запрашивает каталог документов и получает
методологию своего уровня отдельным результатом инструмента. Всего три обращения
к контрольному получателю: начальный контекст с задачей, каталог и документ.

Начальные промпты занимают 1091–1120 символов; схемы инструментов в эту величину
не включены. Project, Domain, Cluster, Container и Component получают 13 команд,
Repo — 14, включая git.status. Общение с командой проверено через наличие
team.list и team.send. Это подтверждает доставку, а не качество решений модели.

В Package объявлены только общие сведения пакета. Данные других уровней не
подмешиваются в его каталог. Полная цепочка локальных правил доступна через
knowledge.read с path ./instructions. Начальный промпт требует запросить её
перед изменениями. Внешний разработчик сохраняет полный инструктивный вход.
