# Навигация MCP

Children помогает агенту понять выбранное направление и выбрать следующий шаг.
Один ответ подходит проекту, компоненту, объединению компонентов и библиотеке:
авторское название говорит, что перед агентом, описание раскрывает назначение,
а адрес позволяет перейти дальше. Тип npm-пакета не подменяет этот смысл.

Дочерние направления показываются кратко и в порядке общего каталога.
Их содержимое раскрывается после перехода. Отсутствие авторского описания
обозначается явно; название и текст не выдумываются из пути.

Ответ содержит собственный `path`: `.` у root и `./путь` у выбранного узла.
Пути элементов `children` имеют тот же формат и отсчитываются от неизменного
root подключения. Например, ответ `./build` содержит переход `./build/descriptor`.
Пустой вызов или `{"path":"."}` возвращает к исходному root.


Дополнительная подпись необязательна. Она сохраняется, когда помогает
ориентироваться, и опускается при буквальном повторе имени в пути или начала
описания. У корневого входа собственное имя сохраняется.

Корневой ответ проекта формирует отдельный [Project MCP](../../../project/env/index.ts).
Children раскрывает выбранные направления и не зависит от конкретного проекта.
Допустимые адреса определяет [MCP Address](../address/README.md).

[Исполняемый пример](spec/scenario.spec.ts) показывает одинаковый ответ
для проекта и компонента.
