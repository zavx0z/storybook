# Корневой вход MCP

Root раскрывает текущий Project: его имя и направления участвующих Repo.
Данные поступают от [Project](../../../../project/index.ts) через HTTP-приложение;
поведение ответа описано в [контракте](./contract/index.ts).
Repo Storybook является одним из возможных участников и не определяет имя Project.

Общая форма ответа и выбор дочерних направлений принадлежат
[Children](../children/README.md), который Root вызывает непосредственно.
Корневой вход не получает фиктивный адрес проекта; к нему обращаются пустым
вызовом. Адреса остальных направлений ограничены
[контрактом адресации](../address/README.md).

[Исполняемый пример](./spec/scenario.spec.ts) включает Project с Repo
и Project с пустым составом.
