# Черновик отображения документа для будущего app

[Компонент ResponseField](document-response.tsx) сохранён из прежнего журнала MCP
как черновик отображения ответа.
Код не подключён к MCP, Workbench, exports или сборке приложения.
Пакет app здесь ещё не оформлен; это только временное место хранения.

[Прежний интеграционный тест](document-response.test.ts.txt) сохранён как текст,
чтобы не запускать проверку удалённого из журнала поведения. При переносе в app
его нужно адаптировать к компоненту и тестовой среде приложения; прежние импорты
и монтирование McpWindow описывают старую интеграцию, а не будущий контракт app.

[Прежний форматировщик Markdown](scenario-markdown.ts.txt) также сохранён только
как черновик. При переносе в app его нужно согласовать с действующим деревом
сценариев.

Текущий MCP передаёт пакетную навигацию с адресом, названием при необходимости,
описанием и непосредственными дочерними пакетами. Отображение для человека
принадлежит app, а не MCP-прокси.
