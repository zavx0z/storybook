# Готовая сборка Web

[Сборщик](../src/browser-build.ts) запускает Bun.build по явному запросу.
[Владелец ресурсов](../src/assets.ts) объединяет только одновременно выполняемые
запросы. Завершённая операция не служит кэшем следующего запроса.

Изменение файлов во время компиляции само по себе не отменяет её результат.
Web не снимает отпечатки исходников, не наблюдает весь Repo и не сверяет его
до и после сборки. Проверки сценариев выполняются отдельно.

Успешная подготовка создаёт кандидата. Явное применение атомарно заменяет
указатель на текущий результат; ошибка компиляции или записи сохраняет прежний.
Начало новой подготовки снимает прежнего кандидата, чтобы после отказа нельзя
было случайно опубликовать результат предыдущего запроса.

При запуске сервера [чтение результата](../src/receipt.ts) восстанавливает
опубликованные файлы без компиляции и без сравнения с редактируемыми исходниками.
Их адреса и контрольные суммы относятся к готовым артефактам: открытая страница
может продолжить использовать свою платформу до применения обновления.
Отпечатка исходников и решения о cache hit у Web нет.
