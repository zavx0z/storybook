# Выбор проверки в основной области просмотра

Проверено на работающей странице Package Env после применения Web.
При выборе expect документа «Общие правила Package» основной просмотр показывает
прочитанный текст. Нажатие заголовка «Базовое окружение» возвращает декларацию.
Повторное нажатие expect снова показывает документ; ревизия остаётся той же.
Модель отдельно проверяет отсутствие повторного запуска и сохранение пустой строки,
false, null и объекта. Существующие подготовленные результаты без значений
assertions сохраняют прежнее представление.

[Снимок выбранной проверки](./selected-assertion.png).

Исходные значения берутся из выполненных assertions, а не из статических объявлений
expect. Выбор не читает документы заново и не выполняет сценарий. Компонентная
фикстура остаётся смонтированной и скрывается при показе значения проверки.

Web опубликован и применён к Package Env; страница ready/presented, ошибок
текущего представления нет. В консоли вкладки сохранялись прежние сетевые ошибки
перезапуска и ошибка подготовки старой архивной беседы; они не выдаются за
ошибки выбранной проверки или за отсутствие ошибок во всей вкладке.
