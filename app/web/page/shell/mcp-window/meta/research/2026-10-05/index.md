# Независимая прокрутка параметров и ответа

Проверено на работающей странице Immersive с ревизией 6528b4239d78076cbbddfd8d.
Короткий input {} имеет высоту одной строки, response занимает остаток.
В общем журнале выбран один вызов; новые записи не меняли выбранную identity.

После уменьшения окна с 878 до 578 px input viewport составил 149.88 px,
response — 246.12 px. Wheel в input дал смещение 32 px. После отдельного wheel
в response его смещение составило 160 px, input остался на 32 px.
После увеличения окна на 40 px высоты стали 163.88 и 272.12 px; оба смещения
остались 32/160 px. Сохранились DOM identity редакторов и положение шапки.
Размер окна и режим следования последнему вызову после проверки восстановлены.

[Оба независимых редактора в рабочем окне](independent-fields.png).

Владельцем выполнены 28 регрессий и финальная перепроверка пяти layout/history
проверок. Общая проверка TypeScript и сборка прошли. Успех механических проверок
и снимок не обозначают приёмку Владимиром. Координатор активности окон и
механизм загрузки внешних изображений здесь не изменялись.
