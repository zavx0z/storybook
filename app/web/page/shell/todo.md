# Предложения по улучшению Shell

## Точные UI-зависимости частных представлений

- [ ] Проверить оставшиеся общие UI-импорты собственных модулей Shell и закрепить границу проверкой.

**Основание.** При изолированной проверке журнала MCP общий импорт
`@zavx0z/immersive-ui-component` привёл к обработке Terminal и ошибке
`CSS template interpolation must resolve to a primitive value`.
Журнал Terminal не использует. Его импорты уже переведены на точные публичные
пакеты в коммите `14c217df`; отдельный устойчивый дефект Terminal не установлен.

**Почему здесь.** Shell отвечает за композицию собственных представлений
и выбор их зависимостей. Общие импорты ещё есть, например, в
[application](src/application.tsx), [message-view](src/message-view.tsx),
[dependency-view](src/dependency-view.tsx) и
[overview-action-button](src/components/overview-action-button.tsx).
Использование UI не передаёт Shell владение его реализацией или компилятором.

**Предложение.** Для используемых компонентов проверить точные публичные
входы и зависимости, затем заменить неоправданные импорты общего каталога
в собственных модулях Shell. Правомерные общие возможности, например stylesheet
темы, сохранить у их владельца. Вложенные самостоятельные пакеты исследовать
отдельно, не включать их перенос автоматически в эту задачу.

**Проверка готовности.** Изолированная компиляция выбранного представления
использует его реальные необходимые зависимости и не загружает Terminal только
из-за общего индексного входа. Проверка наблюдает фактически разрешённые модули,
а не только строку импорта. Существующие проверки
[общего журнала](test/global-mcp-window.test.ts) и
[сохранения состояния](test/mcp-window-persistence.test.ts) проходят.
Состав JSX, поведение и тема сохраняются; platform code не изменяется.
