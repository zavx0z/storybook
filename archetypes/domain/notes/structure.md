# Предметная область пакета

Domain выражает область с общими понятиями, правилами и отношениями.
Field внутри UI и Parameter внутри Nodes — поддомены, то есть тот же класс Domain.
Пакеты конкретных полей и параметров выражают Component.

Domain и Component взаимоисключающие: собственная исполняемая композиция получает
пакет компонента. Домен может предоставлять понятные публичные пути к входам
вложенных пакетов, сохраняя владельцев реализации. Механизм и ограничения
принадлежат [правилу экспортов](../../package/notes/draft-exports.md).

Наличие вложенных директорий, сходство имён и общий импорт сами по себе не
подтверждают Domain. [Читатель](../index.ts) предоставляет структурные факты,
[нормативный сценарий Package](../../package/spec/scenario.spec.ts) проверяет границу,
состав и публичные входы. Собственный spec у проверяемого Domain не требуется: эти
общие проверки не дублируются в каждой области. Если Domain содержит отдельный
предметный сценарий, существующий [исполнитель App](../../../app/scenarios/index.ts) выполняет его;
наличие и результат такого сценария не подменяются автоматическим успехом.
Эти проверки не доказывают полноту смысла всех предметных правил.

Общий порядок классификации и граница Project/Repo описаны
[единым стандартом](../../notes/draft-structure.md).
