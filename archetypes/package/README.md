# Структура пакета

Пакет объединяет принадлежащий ему код под собственным именем и публичным API.
Архетип помогает понять назначение выбранного пакета, найти его публичные входы
и увидеть, какие части их файлового контракта выполнены.

[Исполняемый пример](spec/scenario.spec.ts) применяет архетип к нему самому:
объясняет идентичность, показывает корневой TSDoc и состав экспортов, проверяет
принадлежность файлов, входы сущностей и наличие контрактов. Другой пакет
выбирается через [параметр пути](notes/input-path.md). Код выбранного пакета
при чтении не исполняется.

Результат сохраняет отсутствующие файлы и непроверенные формы экспортов.
Смысловая полнота типов, единственная основная сущность и управление состоянием
пока отмечены в сценарии как неподтверждённые. Проверка наличия файлов
не означает полного соответствия архитектуре компонента.
