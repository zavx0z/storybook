# Публичные входы и происхождение экспортов

Component публикует одну основную реализацию через default своего index.ts/index.tsx
и именованные типы контрактов. Это может быть функция, класс либо осмысленное
значение; число экспортируемых типов не увеличивает число реализаций.
Назначение и ограничения раскрываются [у Component](../../../component/notes/draft-placement.md).

Domain собирает именованный API через реэкспорты публичных входов владельцев.
Это его самостоятельная ответственность, поэтому абсолютный запрет сводных
реэкспортов к нему неприменим. Происхождение реализации и типов сохраняется.
Внутренние пакеты обращаются прямо к владельцам, не через родительский фасад.
[Предметный смысл API](../../../domain/notes/structure.md) и
[средовые входы](../../../domain/notes/environments.md) принадлежат Domain.

## Файловая цель и символ

Штатный exports направляет один публичный путь на один выбранный файл.
Он не объединяет экспорты файлов; это делает доменный вход.
Прямой подпуть может вести к точному публичному index вложенного пакета без
дополнительной обёртки. Цель exports остаётся внутри дерева пакета;
имя соседнего пакета и ../ не являются допустимой прямой файловой целью.

[Читатель входов](../index/index.ts) проверяет объявленные цели и условия.
[Чтение символов](../src/exports.ts) использует native TypeScript AST/checker:
публичное имя, runtime/type-only, тип и источники объявлений сохраняются отдельно.
Собственный файл, содержащий реэкспорты, не становится владельцем чужих функций.
Export * раскрывается средствами checker; импортированное имя и default
разрешаются до реального объявления. Типовые ссылки контрактов также сохраняют
модуль, имена и владельца. Код проверяемых пакетов не исполняется.

Читатель файловых целей exports отклоняет приватные файлы вложенного пакета,
отсутствующие цели, symlink и выход за границы. При чтении символов проверяется
публичность разрешённого модуля у его владельца. Native декларация .d.ts публичного JS-модуля
сохраняет связь с этим модулем. Неизвестное разрешение не объявляется доказанным.
Состав вложенных владельцев задаётся [корневыми glob Repo](../../repo/notes/structure.md).

## Дублирование и типовые связи

Косметические пути к одной реализации в карте одного пакета не добавляются.
Условия одного пути не являются разными публичными адресами. Требование
внешнего протокола проверяется отдельно от произвольного переименования.
Именование default на уровне домена не является копией реализации.
Типовой alias Input = Output другого владельца также не является запрещённым
путевым alias: он выражает зависимость данных и описан
[у контрактов](../../specs/contracts/notes/draft-contracts.md).

Ресурсные экспорты остаются ресурсными. При публикации файловые цели должны
присутствовать в артефакте; workspaces не гарантирует их упаковку автоматически.
