# Как передать путь проверяемого объекта

Сценарий задаёт путь непосредственно в props своего варианта:

```ts
describe.each([
  {name: "Пакет", props: {path: resolve(import.meta.dir, "../..")} },
])("$name", async ({props}) => {
  const result = await readPackage(props)
  // Проверки результата
})
```

Для другого пути вызывающий код передаёт `readScenario({path: scenarioPath,
props: {path: packagePath}})`. Первый path выбирает сценарий, второй — пакет,
который он проверит. Подстановка выполняется до регистрации внешней таблицы
describe.each и не требует чтения окружения или помощника выбора пути в тесте.

Значения по умолчанию остаются в исходнике. Путь не преобразуется запускателем:
относительный путь получает обычный смысл для вызываемой функции в рабочей
директории пакета сценария. Для однозначного выбора извне передаётся абсолютный путь.

Рабочий пример — [сценарий пакета](../spec/scenario.spec.ts).
Полный контракт подстановки описан у [readScenario](../../../app/scenarios/notes/reading.md).
