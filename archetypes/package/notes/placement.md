# Принадлежность пакета

Корневой пакет самостоятельного монорепозитория проверяется архетипом
[Repo](../../repo/index.ts). Project соединяет независимые Repo ссылками.
Внутри Repo пакет принадлежит ближайшему содержащему его пакету; обнаруженный
состав определяется workspaces и физическим расположением.

Вложенность сама по себе не определяет Domain, Component или Container: класс
подтверждают применимые проверки [сценария Package](../spec/scenario.spec.ts).
Поддомен остаётся Domain. [Container](../../../container/notes/structure.md) имеет
собственную runtime-реализацию композиции принадлежащих компонентов и вложенных
контейнеров с компонентами. Использование зависимости не меняет её владельца.
