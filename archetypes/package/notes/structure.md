# Общая структура Package

Package — единая структурная форма Repo, Domain и Component. Он владеет
идентичностью, публичными входами, зависимостями, документацией и собственными
проверками. Наличие вложенных пакетов не создаёт отдельный класс Container.

[readPackage](../index.ts) читает манифест, модульный TSDoc, публичные входы и
состав workspaces без исполнения потребительского кода. Вложенные владельцы
сохраняют собственные identity. Отсутствие exports допустимо для общей структуры;
применимые обязанности исполняемого входа проверяет Component.

[Сценарий Package](../spec/scenario.spec.ts) проверяет identity, документацию,
принадлежность публичных файлов и отсутствие дублирующих кодовых путей.
[Правило экспортов](draft-exports.md) различает собственную реализацию и публичный
путь домена к вложенному компоненту. Неизвестные формы exports сохраняются
непроверенными, а не объявляются соответствующими стандарту.

Применимые требования к контрактам и исполнению принадлежат специализации.
Незавершённые проверки API, состояния и обогащения данных описаны
[у Component](../../component/notes/verification.md). Файловая полнота Package
не подтверждает эти свойства.
