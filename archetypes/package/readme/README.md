# Обзор пакета

Нынешний читатель возвращает авторский README выбранного пакета как Markdown;
пустой файл отличается от отсутствующего. Это действующее поведение читателя,
пока содержание представлений переносится в код, контракты, TSDoc и spec.
README указывает на заметки владельца и не служит источником смысла для MCP.
