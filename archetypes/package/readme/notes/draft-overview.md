# Откуда берётся описание пакета

Текущий runtime читает пакетный README, но принятый источник смысла для MCP и
Storybook — структура кода, публичные контракты, TSDoc и результаты spec.
README служит указателем на временные заметки по
[их жизненному циклу](../../../notes/note-lifecycle.md). Перенос чтения обзора
из README остаётся разрывом реализации.

## Что делает нынешний читатель

`readPackageReadme` читает обычный `README.md` рядом с `package.json`, если
файл существует. Пустой файл и отсутствие файла различаются. Обнаружение
пакета не зависит от README. Текущий каталог ещё хранит путь к нему, а
`readPackage` включает его текст в результат. Это описание существующего
поведения, не требование писать смысл пакета в README.

Авторский README по [единому стандарту документации](../../../notes/draft-documentation.md)
указывает на заметки владельца. Уникальный ещё не перенесённый смысл остаётся
в заметках до выражения у владельца в коде и проверяемых контрактах.
