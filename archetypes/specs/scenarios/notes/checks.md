# Данные и проверки

В `spec/scenario.spec.ts` два варианта: серверный readPackage и DiagramNode
из соседнего WebXR checkout с настоящим рендером. Оба вызывают readScenario
только с путём. Каждый проверяет данные и сохраняет полный результат через
штатный `toMatchSnapshot`. Из stderr удаляются только измерения длительности Bun.
Изображения отдельно в файлы не записываются.

В `test` проверяются внутренние механизмы, включая параллельные вызовы,
сериализацию и определение среды. Сериализация читает собственные enumerable
properties; функции, promises, ошибки и циклы получают явные метки.

Контекст распознаёт прямые имена describe/test, block-bodied callbacks и each
с подстановками $field. Переименованные registrars, printf placeholders,
concise callbacks и контекст hooks пока не поддержаны. Вложенный test сохраняет
группу своего варианта после await. Вызов непосредственно в describe после
await пока может не иметь группы; такие записи нельзя считать полным покрытием.
