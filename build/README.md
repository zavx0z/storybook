# Сборка

[Сборщик пакета](package-build.ts) подготавливает неизменяемую ревизию.
[Общая сборка](shared-browser-build.ts) предоставляет модули платформы и оболочки.
[Сессия пакета](../sessions/package-session.ts) владеет состоянием ревизий,
а [runtime](../runtime/page-entry.ts) применяет их внутри открытой страницы.
