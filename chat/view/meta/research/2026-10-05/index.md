# Чат: текстовые дельты, память и служебные документы

Задача Владимира: исправить текст сообщений, раскрываемые блоки с форматированием
и подсветкой, снизить память и задержки страницы по существующим заметкам.

## До исправлений

Живая страница `/immersive`, viewport 1920×1088, DPR 2, canvas 3840×2176.
`timeOrigin=1791171826414`. Сборка платформы
`3aa873f1e24f309040f422120a9cd74fbdbb4d439edd66098475aa0e2a36ac77`.
Измерения не вызывают принудительную сборку мусора.

- [CDP heap и пять секунд простоя](before.json): около 85,4 МБ JS heap,
  117,0 МБ backing storage. Native DOM имеет 64 узла; это не число элементов
  semantic Document. За пять секунд task duration около 1,3 мс; данный интервал
  не доказывает отзывчивость ввода и раскрытия документов.
- [Привязанный к странице процесс](process-memory-before-attributed.json):
  `blink.user_timing` marker определяет PID этой страницы в trace,
  `disabled-by-default-memory-infra` показывает private footprint 855,37 МиБ.
  Это размер процесса, а не сумма счётчиков heap. Общий GPU-процесс не приписывается
  целиком этой странице. Значения байтов в исходном trace записаны hexadecimal.
- [Renderer](renderer-before.json): 3101 объект сцены, 1655 CachedText,
  ни одного skinned object. При capacity 1024 CPU и GPU bones занимают по 8 МиБ.
  Геометрия Renderer занимает около 4,36 МБ CPU и столько же GPU.
  Полноразмерные depth/MSAA/presented textures сохраняют качество отрисовки;
  их размеры и samples записаны отдельно, это не измерение resident memory.
- [Text cache](text-before.json): 1107 записей, 52,93 МБ массивов, из них
  551 промежуточный вариант с начальными интервалами, 26,25 МБ, без потребителей
  в текущей сцене. Этот набор пересекается с неактивными записями, не складывается с ними.

## Воспроизведение текста

Сохранённая беседа содержит 12 текстовых дельт короткого ответа и 266 дельт
следующего. Сессия корректно сохраняет их порядок, но представление создавало
Markdown на каждую дельту. Проверка `spec/streamed-content.spec.ts` до исправления
получила семь абзацев `В`, `иж`, `у`, `два`, `наб`, `ора`, `.` вместо одного.

Отображение объединяет только соседние текстовые блоки. Между мультимедиа границы
сохраняются. Исходные timeline, ACP metadata и raw updates не переписываются.
Это исправляет и уже сохранённые истории без миграции.

## Проверка результата

После общей публикации повторяются замеры на той же странице, раскрытие и закрытие
служебного документа, прокрутка и ввод. Смена timeOrigin, сборки, числа раскрытых
панелей или принудительная GC должны быть указаны явно. Прохождение тестов не
заменяет живую проверку; этот раздел дополняется фактическими результатами.

[Одинаковая последовательность действий до изменений](interaction-before.json):
заполнение пустого черновика, очистка, раскрытие и закрытие начального контекста.
Сообщение не отправлялось. CDP task duration: 584,8 / 287,0 / 611,9 / 116,3 мс.
Это интервал всей команды среды, включая её snapshot overhead, а не чистая задержка
клавиатуры. Исходное пустое поле и свёрнутый контекст проверены перед запуском;
в конце они восстановлены. Тяжёлая локальная компиляция к этому моменту завершилась.

Семантическая проверка после исправления: четыре теста, 24 assertions,
потоковый и повторно открытый Markdown, ленивые детали, подсветка JSON и TS source,
освобождение CodeEditor при закрытии и сохранение metadata. Renderer/GPU в этом
прогоне не создаются; compiler startup занял основную часть 218 секунд.

[Отдельный прогон с CPU sampler](interaction-before-profile.json) подтверждает,
что интервал команды включает `nodeForId`/`visit`/`resolveTarget` инспектора наряду
с подготовкой компонентов и Renderer. Поэтому сравнение этих интервалов нельзя
выдавать за измерение чистого ввода человека. `(program)` и idle samples не
атрибутируются прикладным функциям; sampler может менять стоимость прогона.

[Прямой подсчёт semantic элементов](renderer-before-ui-counts.json), сделанный
после цикла раскрытия/закрытия: 4520 элементов, три обычных сообщения и 264 абзаца
в них; два CodeEditor, 517 строк. Native DOM остаётся отдельной метрикой.

## Проверенная промежуточная сборка A

Платформа `fcbbb6883ca56c88a09c5529fba497acedf2f1db444f50fca4f092df3b6b8d7a`,
Web `9792443b548e2e248f58e5c0c521f4cfbbcec1ac3666f1a20fbfcbcd4ebf9108`.
Страница ready/presented, diagnostics и consoleErrors пусты. Поле очищено после
проверки; сообщения модели не отправлялись. Снимок просмотрен, текст читается
цельными словами, Markdown выделения работают.

[Renderer](renderer-after-a.json): 3169 semantic элементов вместо 4520,
6 абзацев вместо 264 в тех же трёх сообщениях; два редактора и 517 строк сохранены.
CPU bones 0, GPU bones 8192 байта, DPR/canvas/MSAA неизменны.
[Text cache](text-after-a.json): 23,02 МБ массивов вместо 52,93 МБ;
1380 активных leases, около 0,19 МБ неактивных данных при лимите 16 МиБ.

Первый [process snapshot](process-memory-after-a.json) относится к фоновой вкладке
и не используется как сопоставимый показатель. После активации той же вкладки
[private footprint](process-memory-after-a-visible.json) составил 190,33 МиБ.
[Контекст и idle](after-a-visible.json): та же геометрия viewport, visible,
JS heap 84,23 МБ и backing storage 42,53 МБ. Сменились timeOrigin и процесс:
это состояние после обновления, а не доказательство, что весь спад с 855 МиБ
объясняется одной правкой. Принудительная GC не использовалась.

[Повтор тех же действий](interaction-after-a-visible.json): CDP task duration
380,2 / 159,2 / 388,2 / 79,7 мс для fill / clear / context-open / context-close.
Интервалы по-прежнему включают служебную инспекцию, а не только ввод человека.

После этой сборки в исходниках ChatData отключены визуальные softBreaks и скрытие
escape-символов: обнаружено искажение JSON при настоящем копировании. Без этих
опций [узкий probe](formatted-copy.json) сохраняет значения и валидность JSON,
но точная форма source ещё отличается лишними whitespace. Это не успешная
проверка exact copy. Последние две удалённые настройки не публиковались отдельной
дорогой Web-сборкой перед запрошенным Git checkpoint.
Виртуализация и общий source-text root остаются следующим незавершённым этапом.
