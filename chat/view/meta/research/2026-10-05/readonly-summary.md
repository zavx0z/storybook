# Readonly окно: проверка общего исходника и живой страницы

Платформа `c3e1fad1fb9166e7bc5448a7c7b38f9e80bfd096dbca9c034768571c29c2f690`,
Web `6eecfc6f78811b1cca09ff48a27ea90c5b72871e55aa39c43b07461d1f312512`.
Общая сборка и применение Immersive завершились успешно. Страница ready/presented,
diagnostics и consoleErrors пусты. Viewport 1920×1088, DPR 2, Canvas 3840×2176,
MSAA 4. TimeOrigin `1791176054713.2` сохранился от промежуточной сборки A.

## Поведение и стоимость

- В том же обычном состоянии [semantic элементы](renderer-readonly-base.json)
  уменьшились с 3169 до 975, строки двух редакторов — с 517 до 34.
- [Синтетический файл](readonly-fixture.ts.txt): 13 001 строка, 521 907 байт,
  CRLF и конечный маркер. Файл прочитан целиком обычным инструментом среды;
  результат закреплён в общем журнале, не обрезан. Полный форматированный JSON
  содержит 548 153 символа и 13 010 visual rows.
- [В начале](readonly-large-pinned.json) создано 33 строки,
  [в конце](readonly-large-final-end.json) — 33; промежуточно 34 из-за закреплённой
  широкой строки. Полный DOM source и конечный маркер остаются на месте.
  ScrollTop достиг 207 770; последняя visual row имеет индекс 13009.
- [Возврат к началу](readonly-large-return.json), [горизонтальное движение](readonly-large-right.json)
  до 36,6 px и [возврат](readonly-large-left.json) сохраняют содержимое.
  [Снимок конца](readonly-large-end.png) просмотрен: строки 12983–12999,
  конечный маркер и metadata видны, подсветка работает.
- [После закрытия](readonly-closed.json) большой исходник отсутствует в DOM,
  элементов 990. [Повторное открытие](readonly-reopened.json) восстанавливает
  все 548 153 символа, 34 строки и прежнюю прокрутку. [Повторное закрытие](readonly-reclosed.json)
  вновь даёт 990 элементов. JS heap двух закрытых состояний около 58,46 и 58,90 МБ;
  это короткая серия, не доказательство отсутствия любой долгосрочной утечки.
- [Private footprint с открытым документом](process-memory-readonly-large.json)
  около 195,33 МиБ. [После закрытия](process-memory-readonly-closed.json) — 265,05 МиБ;
  между этими замерами был GPU readback для снимка. Их нельзя выдавать за чистую
  стоимость закрытия или потолок памяти. Явная GC и queryObjects не использовались.
  [Текстовый кэш после закрытия](text-readonly-closed.json): active 6,14 МБ,
  inactive 8,65 МБ, ниже лимита 16 МиБ; GPU bone binding 8192 байта.

Колесо доставлялось настоящим CDP Input.dispatchMouseEvent на координаты текущего
публичного getBoundingClientRect. Присваивания scrollTop из диагностического кода,
вызова обработчиков вручную и дополнительного Canvas не было. Второй wheel в конце
прокрутил внешний контейнер журнала, чтобы нижняя часть вложенного viewport была
видна. После проверки общий журнал снова закрыт; состояние локального окна сохранено.

## Проверки исходника

42 проверки DOM/Renderer/Browser, включая leases/adoption/GC и настоящий
ClipboardController с подменой только OS access; 33 проверки CodeEditor,
включая native drag/Shift-drag, exact copy, CRLF, Unicode, resize, source shrink,
переключение readonly/editable и обычное редактирование; шесть интеграционных
проверок Chat View. Все прошли. Типы DOM, Renderer HTML, Browser, CodeEditor,
Markdown и Storybook проходят.

ChatData снова использует визуальные softBreaks и скрытие escape-символов;
копирование теперь читает исходный DOM source. Проверяется точное равенство,
а не только успешный JSON.parse. Markdown и журнал ограничивают CSS высоту
блока 400px, чат — 240px; большой readonly документ имеет собственную прокрутку.
Редактируемые большие документы остаются прежним отдельным направлением;
эта порция не заявляет их виртуализацию.

После серии восстановлены исходные условия общего журнала: выбран режим слежения
за последней командой и окно закрыто. [Снимок состояния](readonly-restored.json)
подтверждает отсутствие большого документа и пустой черновик чата.
Повторены четыре [команды чата](interaction-readonly-final.json): fill / clear /
context-open / context-close дали 298,4 / 97,9 / 115,3 / 61,8 мс CDP task duration.
Для сравнения до исправлений было 584,8 / 287,0 / 611,9 / 116,3 мс. Это полные
интервалы служебных команд с их инспекцией, не замеры чистой задержки клавиатуры.
Текст был очищен, контекст снова свёрнут, prompt модели не отправлялся.
