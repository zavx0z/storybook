# Смысловая группа с общим протоколом

Основанием принадлежности самостоятельных компонентов служит общий протокол,
которым владеет кластер. Каждый участник сохраняет свою реализацию и собственный
протокол, соответствующий общему. Участник может расширять его своими особенностями.

Участники выполняют одну общую роль и функцию. Замена одного участника другим
в этой роли сохраняет смысл применения; конкретный участник добавляет свои
особенности. Общий протокол выражает эту общую возможность и её гарантии.
Одного совпадения входных данных для принадлежности кластеру недостаточно.

У Domain общность определяется предметным
смыслом и инвариантами одной сущности, а функции её воплощений в разных средах
могут различаться.
