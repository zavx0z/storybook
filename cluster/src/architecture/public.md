# Смысловая группа с общим протоколом — Публичность и происхождение

Организация доступа к набору самостоятельных компонентов и именованное раскрытие
их возможностей относятся к Cluster. При реэкспорте реализации и собственные
типы участников сохраняют исходных владельцев. Кластер владеет своим общим
протоколом; прежний запрет собственного контракта у Domain-фасада к нему неприменим.

Основной index раскрывает именованные реализации участников и их пространства
типов, включая общий namespace самого кластера. Единственный дополнительный
кодовый вход ./contract публикует только этот общий namespace. Дети используют
его через имя пакета, не импортируя runtime-фасад родителя. Дополнительные
ресурсы следуют общим правилам Package.

Общие правила identity, зависимостей, публичных адресов и безопасного чтения
принадлежат Package.
