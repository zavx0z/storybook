# Несколько представлений одного компонента

Разные варианты использования не создают самостоятельных пакетов автоматически.
Они относятся к одному Component, когда сохраняют его публичный контракт и
реализацию. Принадлежность сценария определяется его владельцем.

Обычные варианты описываются в `describe.each` собственного `spec/scenario.spec.ts(x)`
по правилу сценариев.
Например, числовой параметр может иметь несколько вариантов входных данных.

Способ выражения нескольких готовых preset-представлений одного компонента
ещё не согласован. Пример Socket требует проверить, достаточно ли существующей
структуры spec для этой связи. Нужны исполняемый пример и его проверка;
новую проектную декларацию привязки ради этого не вводят.
