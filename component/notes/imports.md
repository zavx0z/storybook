# Импорты внутри пакета и между пакетами

Внутри одного пакета в статических, динамических и type-only импортах директорий
имена `index.ts` и `index.tsx` опускаются: `./fixture` вместо `./fixture/index.ts`.
Краткий путь должен разрешаться в тот же существующий модуль. Для сокращения
импорта не создаются новые index-файлы или реэкспортные фасады.

Между самостоятельными пакетами используются публичные входы точных владельцев.
Это относится и к import type. Домен раскрывает контракт наружу, но внутренний
потребитель не импортирует его назад через фасад родителя.
Относительный путь к чужому `src` не заменяет dependency и публичный контракт.
Доменный подпуть может непосредственно открывать публичный вход вложенного пакета
по [правилу экспортов](../../archetypes/package/notes/draft-exports.md).
Пути к файлам в `package.json#exports` остаются явными.

Автоматическая проверка сокращения внутренних импортов ещё не реализована.
Пример подготовки данных сценария находится
[у читателя App](../../app/spec-reader/spec/parameterization.spec.ts).
