# Где размещать компонент и его реализацию — Вход компонента и его внутренние части

Основная реализация находится в корневом `index.ts` либо
`index.tsx`. Вход предоставляет одну основную реализацию через default и именованные
типы её контракта. Дополнительные самостоятельные компоненты получают свои
пакеты. Подмена реализации реэкспортным фасадом не допускается.
Публичные входы и экспорт контрактных типов.

Отдельные вспомогательные функции и частные компоненты отображения верхнего
уровня выносятся в `src/` своего пакета. Небольшой размер не является основанием
оставлять несколько таких объявлений во входе. Локальные обработчики и callbacks
внутри основной реализации остаются её частью. Связанные помощники могут
находиться в одном частном файле; одного экспорта на каждый файл `src` не требуется.
Если выносить нечего, `src/` не создаётся.

Самостоятельная общая часть нескольких пакетов получает собственного владельца
и используется через его публичный API. Соседние пакеты не импортируют чужие
`src/`. Частный общий код внутри одного пакета остаётся его
реализацией и не создаёт отдельный структурный класс.

Типовые роли и определения публичной формы находятся в `contract/`,
а нужные только реализации типы — у использующего кода.
Точка namespace, размещение определений и публикация типов следуют
правилам Contracts.
Наличие частных helpers не определяет доступность документации или сценария.
