# Композиция компонентов

Он определяет совместную работу принадлежащих компонентов и вложенных
контейнеров. Единственный публичный индексный вход предоставляет основную
реализацию через default и протокол целого. Реализация может работать в одной
среде или быть переносимой между несколькими; переносимость не создаёт Domain.

Части сохраняют собственные реализации и контракты. Дочерние компоненты
не получают дополнительные публичные адреса через контейнер.
Группировка самостоятельных участников общего протокола принадлежит
Cluster, а связь средовых реализаций
одной сущности — Domain.

Принадлежность частей выражена физической вложенностью пакетов и составом
корневого workspace Repo. Использование внешней зависимости не делает её
внутренней частью контейнера. Частные helpers в src не являются самостоятельными
частями и сами по себе не превращают Component в Container.

Пример устройства:

```text
container/
├── index.ts              собственная реализация целого
├── contract/             её вход и выход
├── spec/                 применение и поведение целого
├── component/
└── nested-container/
    └── component/
```
