# Одна сущность и её средовые реализации — Публичные входы

Каждый вход среды предоставляет одну основную реализацию и соответствующий
протокол. Общий индекс не обязателен; выбор входа описан
в правилах сред.
Реализации и протоколы разных сред могут различаться по обязанностям внутри
одной сущности. Их происхождение сохраняется по
правилам Package и
Contracts.

Внутренние участники обращаются к публичным входам фактических владельцев.
Реэкспорт не переносит реализацию или декларацию типа к публикующему пакету.
Общие определения не копируются ради одинакового вида средовых протоколов.
Протокол принадлежит самому Domain либо точно выбранному владельцу основной
реализации. Default-реэкспорт сохраняет этого владельца и не требует фиктивной
обёртки. Собственные средовые namespace размещаются в contract рядом с общими
определениями: contract/web.ts для web.ts, contract/server.ts для server.ts.
