# Адрес публичного владельца

Адрес выбирается из path в children предыдущего ответа. Он принадлежит
пакету, категории или функции в едином каталоге Storybook. Уровни разделяются
`/`; точка остаётся частью имени. Пустой вызов открывает [Root](../root/README.md).

[Исполняемый контракт](spec/scenario.spec.ts) проверяет точное совпадение.
Неизвестный адрес не сокращается до родителя. Query, fragment, начальный
и конечный слеш отклоняются. Частные файлы и директории не входят в каталог.

Окно MCP использует того же владельца, что открытая страница. Параметры страницы
выбирают представление в интерфейсе и не меняют публичный адрес владельца.
