# HTTP-вход MCP

Пустой запрос открывает [Root](../root/README.md). Поле path выбирает адрес
из children предыдущего ответа. [Address](../address/README.md) проверяет точное
присутствие адреса в публичной структуре того же каталога, который показывает Workbench.

Назначение берётся из модульного TSDoc владельца, а при его отсутствии — из
непосредственного package.json. В списке детей используется краткое назначение
пакета из package.json либо первый абзац TSDoc директории. Категория сохраняет расположение детей;
[Children](../children/README.md) раскрывает только один следующий уровень.
Частные src, contract и spec не становятся отдельными переходами.

Выбранный владелец дополнительно раскрывает input и output как JSON Schema.
TypeDoc строит их из разрешённых TypeScript-типов и описаний TSDoc в той же
сессии разбора, что формирует справочник для интерфейса. Поля, обязательность,
массивы, enum, union и ссылки рекурсивных типов сохраняют смысл контракта.
Свободный текст не превращается в выдуманные ограничения.

Scenarios сохраняет исходники bun:test. Чтение не исполняет код, не запускает
тесты или сборку и не раскрывает соседние ветви. У отсутствующего источника
нет поля; категория не заимствует контракт детей.

Пути исходных файлов и отпечатки каталога остаются внутри читателя.
Сменившийся после обнаружения контракт отклоняется до обновления каталога.
MCP-прокси передаёт предметный JSON без преобразований.
[Полные отчёты запусков](scenarios/README.md) имеют отдельного владельца;
они не подменяют исходники в этом входе.

## Журнал

Журнал MCP хранит последние 20 запросов: имя инструмента, параметры, время,
статус и полный публичный ответ без обрезки по длине. Окно журнала показывает
одну выбранную команду. Окно показывает тот же полный JSON, который получает агент, в одном
CodeEditor с отступами и подсветкой JSON. Поля не извлекаются в отдельное
представление; исходная запись ответа не изменяется. Кнопки переключают команды,
а не страницы ответа; все 20
записей остаются в истории. По умолчанию показывается последняя команда,
выбор более старой сохраняется при новых обращениях. Служебные
секреты и внутренние адреса проходят обычную очистку публичной границы MCP.
Для `storybook_capture` журнал сохраняет метаданные и `captureId` без base64,
отдельно загружает PNG через авторизованную browser-сессию и показывает превью.

Второй режим [окна MCP](../../workbench/mcp-window/README.md) определяет точного владельца
открытой страницы по общему графу. В показанный запрос входит его публичный
адрес; параметры интерфейса туда не попадают.
Корневая страница соответствует пустому запросу. Browser-сессия обращается
к тому же REST-обработчику и не добавляет запись в журнал вызовов агента.

HTTP-приём записи журнала допускает до 8 МиБ в UTF-8 на запись, отдельно от
лимита 64 КиБ обычных управляющих команд. Размер проверяется и по заголовку,
и при чтении потока; превышение отклоняется целиком, без усечения ответа.

Статус сервера содержит requestJournal: состояния последних записей, размеры
входов и ответов в UTF-8 и последнюю ошибку приёма записи. Сводка не включает
содержимое ответов и доступна независимо от работоспособности окна журнала.
