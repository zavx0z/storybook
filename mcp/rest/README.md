# Storybook REST

Пакет предоставляет обработчик единой точки входа HTTP API. Основной сервер
Storybook подключает его после проверки авторизации.

Пустой запрос возвращает только обзор пакетов Archetypes и Валидатор.
Описание пакета читается из package.json при каждом обращении. Каждый дочерний
раздел содержит только node для следующего запроса и description. Запрос
`{"node":"archetypes"}` раскрывает публичные экспорты Archetypes; назначения
читаются из первых смысловых абзацев README соответствующих определений.
Вложенные пакеты раскрываются таким же образом через собственные exports.
Отдельного дерева маршрутов и сгенерированного каталога нет. Технические
директории, не объявленные публичными входами, не открываются через node.
Успешный обзор не содержит служебных status и schemaVersion.

Конечный раздел с непосредственным spec/scenario.spec.ts либо .tsx выполняет
этот тест и возвращает scenarios — одно дерево вариантов, категорий и пунктов.
MCP передаёт JSON HTTP-сервера без отдельной текстовой проекции. Например,
archetypes/specs/scenarios возвращает руководство с исполняемыми примерами
функции и компонента. У каждого пункта находятся его описания, данные и состояния
проверок. Отдельного оглавления, Markdown-копии и случайной ревизии в обычном ответе нет.
Два сценарных файла одного владельца считаются неоднозначностью.

input.variant выбирает вариант по имени, input.section — цепочку имён тем.
Имена читаются из label в дереве. variants содержит варианты, children — вложенные
категории, items — пункты. Пустые структурные списки отсутствуют; реальные значения
actual не очищаются. Для input.section берутся label вдоль выбранной ветки.
Выбранная тема возвращается целиком с родительской цепочкой, без соседних ветвей.
action=data возвращает прежнее диагностическое поле scenarios с actual,
expected, matchers и техническими сведениями; никакие данные не удаляются.

На этом этапе каждый запрос такого раздела запускает тест. Кэширование
и подготовка при сборке ещё не подключены; это не кэшированный production-цикл.
Произвольные пути через input пока не поддержаны.

MCP передаёт запрос серверу и возвращает его ответ. Логика обзора принадлежит
этому пакету и исполняется в HTTP-сервере. [Сценарии](scenarios/README.md) и
[чтение спецификации пакета](package/index.ts) также принадлежат этой стороне.
Независимость транспорта закреплена в [сценарии прокси](../proxy/spec/scenario.spec.ts)
и [сценарии MCP-адаптера](../server/spec/scenario.spec.ts).

Журнал MCP хранит последние 20 запросов: имя инструмента, параметры, время,
статус и полный публичный ответ без обрезки по длине. Окно журнала показывает
параметры и ответ в отдельных полях CodeEditor с подсветкой JSON. Служебные
секреты и внутренние адреса проходят обычную очистку публичной границы MCP.
Для `storybook_capture` журнал сохраняет метаданные и `captureId` без base64,
отдельно загружает PNG через авторизованную browser-сессию и показывает превью.
