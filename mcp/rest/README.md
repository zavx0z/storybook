# Storybook REST

Пакет предоставляет обработчик единой точки входа HTTP API. Основной сервер
Storybook подключает его после проверки авторизации.

Пустой запрос возвращает только обзор пакетов Archetypes и Валидатор.
Описание пакета читается из package.json при каждом обращении. Каждый дочерний
раздел содержит только node для следующего запроса и description. Запрос
`{"node":"archetypes"}` раскрывает публичные экспорты Archetypes; назначения
читаются из первых смысловых абзацев README соответствующих определений.
Успешный обзор не содержит служебных status и schemaVersion. Более глубокое
раскрытие и действия пока недоступны.

MCP передаёт запрос серверу и возвращает его ответ. Логика обзора принадлежит
этому пакету и исполняется в HTTP-сервере.

Журнал MCP хранит последние 20 запросов: имя инструмента, параметры, время,
статус и полный публичный ответ без обрезки по длине. Окно журнала показывает
параметры и ответ в отдельных полях CodeEditor с подсветкой JSON. Служебные
секреты и внутренние адреса проходят обычную очистку публичной границы MCP.
Для `storybook_capture` журнал сохраняет метаданные и `captureId` без base64,
отдельно загружает PNG через авторизованную browser-сессию и показывает превью.
