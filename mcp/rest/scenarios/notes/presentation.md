# Подготовленное представление сценариев

Внутренний читатель сценариев подготавливает предметный документ функции,
компонента или другого владельца. `sections` содержит вложенные разделы,
`title` называет каждый раздел, а `content` содержит его абзацы. Этот читатель
не входит в текущую пакетную навигацию MCP.

## Разделы и содержание

Внешние варианты, вложенные группы и пункты сценария становятся разделами
одной формы. Их заголовки берутся из исходного сценария. Пункты и категории
внутри одного родителя сохраняют общий порядок исходника, а не расходятся
по отдельным спискам.

Абзац содержит `text` с авторским пояснением и, при наличии выполненного
примера, `value` с предметными данными. Несколько абзацев сохраняют связь
каждого пояснения с его значением. Пример кода также может быть значением:
форматировщик не сочиняет его и не определяет смысл по имени проверяемой функции.
Для поддержанного компонентного сценария внешний вариант содержит декларацию,
конкретные props и пункты из того же `preview`, который использует приложение.
Обычные разделы с фактическими actual и состояниями проверок при этом сохраняются.

Имена тестового API не используются ключами структуры документа. В исходнике
заголовок поступает из label, пояснение — из customFailMessage, значение — из actual.
Условия matcher и технические сведения остаются в диагностическом каталоге.
Если предметное значение само содержит поля с такими именами, они сохраняются
внутри value: форматировщик не удаляет пользовательские данные по имени ключа.

Пустые структурные списки опускаются. Пустые значения null, строки, массивы,
объекты, false и ноль сохраняются. Невыполненный пример не получает выдуманного
value. Заметки notes обозначают неподтверждённое положение, неприменимость
примера, ошибку либо ожидаемое несоответствие; отсутствие ошибки не доказывает
смысловую полноту документации. Нарушения общего отчёта validation обозначаются
заметкой у корня документа; подробности остаются в диагностическом каталоге.

## Выбор раздела во внутреннем читателе

Подготовленное представление может выбрать вариант по названию и вложенную тему
по цепочке заголовков. Оно сохраняет выбранную тему и её родителей без соседних
тем. Неизвестный или неоднозначный заголовок вызывает ошибку. Выбор не расширяет
публичный пакетный адрес MCP.

## Источник и диагностика

[readScenarios](../index.ts) принимает подготовленный публичный результат
`readSpec` либо вызывает `readSpec({path})` сам. По умолчанию результат превращается
в документ; внутренний режим `data` сохраняет доступ к диагностическому каталогу
с preview, идентификаторами, условиями, исходными состояниями и validation из
того же запуска.
Полный результат инспектора остаётся неизменным и принадлежит общему механизму
чтения сценариев.

Разделы и содержание подготовленного документа поступают из результата
сценария. Вызывающий код может передать результат применённой ревизии;
без него читатель выполняет спецификацию через публичный API владельца.

Один преобразователь проверяется на сценариях репозитория, сущности, пакета,
обычной функции и визуального компонента. Он не содержит отдельных правил
для руководства Archetypes. Изменение подготовленного документа не меняет
пакетный ответ MCP; независимость прокси подтверждают [сценарий прокси](../../../proxy/spec/scenario.spec.ts)
и [проверка зависимостей](../../../proxy/test/boundary.test.ts).
