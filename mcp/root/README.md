# Корневой вход MCP

Root — начальная точка входа Storybook MCP. Она объясняет, как выбрать
направление и перейти к нему, и показывает текущие подключённые проекты.
Её собственные название и описание сохраняются при добавлении и удалении
проектов и при пустом каталоге.

Проект разработки Storybook является обычным подключённым направлением.
Root не читает его README или package.json для собственного содержания
и не требует его присутствия.

Общая форма ответа и выбор дочерних направлений принадлежат
[Children](../children/README.md), который Root вызывает непосредственно.
Корневой вход не получает фиктивный адрес проекта; к нему обращаются пустым
вызовом. Адреса остальных направлений ограничены
[контрактом адресации](../address/README.md).

[Исполняемый пример](spec/scenario.spec.ts) включает подключённый проект
и пустой каталог.
