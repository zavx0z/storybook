# Что описывает Package

[Package](../../index.ts) владеет общей identity, составом, публичными входами и
ресурсами. Конкретные обязанности Domain, Cluster, Container, Component и Repo раскрываются у
[своих архетипов](./draft-structure.md).

- [Имя и состав](../../package-json/meta/notes/draft-identity.md)
- [Описание из кода](./draft-overview.md)
- [Публичные пути и владение](./draft-exports.md)
- [Обнаружение](./draft-discovery.md)
- [Ресурсы](./draft-ownership.md)

Существующие файловые проверки не являются полной смысловой оценкой стандарта.
