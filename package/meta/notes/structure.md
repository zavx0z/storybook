# Общая структура Package

Package — единая структурная форма Repo, Domain, Cluster, Component и Container. Он владеет
идентичностью, публичными входами, зависимостями, документацией и собственными
проверками. [Container](../../../container/meta/notes/structure.md) выражает собственную
композицию принадлежащих вложенных компонентов и контейнеров в одно целое.
Вложенность без собственной runtime-реализации не подтверждает Container.

[readPackage](../../index.ts) читает манифест, модульный TSDoc, публичные входы и
состав workspace Repo, Git-границу, происхождение экспортов и ссылки контрактов без исполнения
потребительского кода. Вложенные владельцы
сохраняют собственные identity. Читатель возвращает структурные факты
и при отсутствии exports.

Правила публичных входов находятся в частных разделах
[сценария Package](../../reader/spec/scenario.spec.ts). Отсутствующий exports читатель
нормализует в пустую карту; проверка типа этой карты не требует объявления API.

[Сценарий Package](../../reader/spec/scenario.spec.ts) проверяет identity, документацию,
принадлежность публичных файлов и отсутствие дублирующих кодовых путей.
Условные разделы Repo, Domain, Component и Container пока раскрывают прежние
специализированные правила. Новые определения Domain и Cluster закреплены
[в структурном стандарте](./draft-structure.md), а необходимые изменения —
[в плане перехода](./archetype-transition.md).
Repo сохраняет право не объявлять собственный публичный API.
Применимость и примеры выражены в коде этого сценария; результат относится
к конкретному запуску. Интерфейс и сборщик используют его полный отчёт
без собственного реестра классов или выбора по названию отдельного теста.
Текущий [вход MCP](../../../app/knowledge/README.md) раскрывает исходник сценария,
но не отчёт выполненных проверок.
[Чтение экспортов](./draft-exports.md) различает собственную реализацию и публичный
файл вложенного владельца. Неизвестные формы exports сохраняются
непроверенными, а не объявляются соответствующими стандарту.

Применимые требования к контрактам и исполнению принадлежат специализации.
Незавершённые проверки API, состояния и обогащения данных описаны
[у Component](../../../component/meta/notes/verification.md). Файловая полнота Package
не подтверждает эти свойства.
