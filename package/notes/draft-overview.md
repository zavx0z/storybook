# Откуда берётся описание пакета

`readPackage` получает описание из модульного TSDoc корневого `index.tsx` или
`index.ts`. README остаётся указателем на заметки по
[их жизненному циклу](./note-lifecycle.md) и не входит в результат
чтения пакета. Обнаружение пакета не зависит от README.

Уникальный не перенесённый смысл сохраняется в заметках до его выражения у владельца в коде,
контрактах, TSDoc и исполняемых spec.

Согласованный Domain может предоставлять только средовые входы без общего
индекса. Его документация должна читаться из этих входов с сохранением условий
и соответствующих протоколов. Текущий index-only reader этого ещё не обеспечивает;
[план перехода](./archetype-transition.md) не требует фиктивного index или README fallback.
