# Чтение состава конкретного Project

[readProject](../../index.ts) читает собственное имя и установленные зависимости
Project из `package.json` в его точном Git-корне. Участники объявляются в
`dependencies`, затем `devDependencies`; их версии и установка принадлежат
пакетному менеджеру. Читатель разрешает каждый ключ непосредственно как
`Project/node_modules/<key>` и читает манифест по физическому пути, поэтому
публичный `exports` пакета не ограничивает чтение состава.
Контракт и обработка ошибок описаны у [Project](../../contract/index.ts),
успешное использование проверяется [сценарием](../../spec/scenario.spec.ts).

Локальная ссылка в `node_modules` раскрывает канонический пакет исходного checkout
без копирования. Несколько пакетов одного Repo сохраняют общий Git-корень;
повторные ссылки на один пакет объединяются. Имя читается из фактического
манифеста пакета, включая использование npm alias. Установленная npm библиотека
участвует без собственной Git-истории и не становится Repo из-за Git Project.
Для обнаружения каталог выбирается как `dependency.repository ?? dependency.root`;
одинаковые выбранные корни объединяются потребителем.

Конкретное размещение `zavx0z` не зашито в читателе. Repo может участвовать
в разных Project с сохранением своей identity и истории. Состав пакетов Repo
по-прежнему определяется его `package.json#workspaces` и читается отдельным
[владельцем Repo](../../../repo/reader/index.ts). Читатель Project не сканирует
соседние директории и вложенные пакеты, не использует `.gitmodules` или
сохранённый список каталогов Storybook. Отсутствующая объявленная установка
прерывает чтение и не заменяется найденным рядом checkout.

Изменение объявлений отражается при следующем чтении. Операции установки,
создания, подключения, клонирования и удаления Repo, сохранение переписок
и агентный жизненный цикл Project остаются отдельными направлениями.
Чтение состава не реализует эти операции и не изменяет рабочие деревья.
Кнопки добавления и удаления сохраняются в интерфейсе отключёнными (`disabled`);
соответствующие endpoints возвращают 501 и не изменяют состав Project.
