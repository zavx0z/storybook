# Чтение состава конкретного Project

[readProject](../../index.ts) читает Project как Git superproject. Собственное имя
задаёт `package.json#name`, участвующие Repo объявляются в `.gitmodules`.
Читатель использует штатный parser Git config и читатель собственного манифеста.
Контракт и обработка ошибок описаны у [Project](../../contract/index.ts),
успешное использование проверяется [сценарием](../../spec/scenario.spec.ts).

Конкретное размещение `zavx0z` не зашито в читателе. Repo может участвовать
в разных Project с сохранением своей identity и истории. Git superproject
фиксирует участие и версии gitlinks; собственный состав пакетов каждого Repo
по-прежнему определяется его `package.json#workspaces`.
Ссылка Project раскрывает корень и имя Repo. Пакеты и документацию Repo читает
отдельный [владелец Repo](../../../repo/reader/index.ts); неверный манифест вложенного
пакета не меняет объявленное участие самого Repo в Project.

Изменение объявлений отражается при следующем чтении. Читатель не восстанавливает
состав из списка каталогов Storybook и не создаёт отдельное постоянное хранилище.
Операции создания, подключения, клонирования и удаления Repo, сохранение переписок
и агентный жизненный цикл Project остаются отдельными незавершёнными направлениями.
Чтение состава не реализует эти операции и не изменяет рабочие деревья.
