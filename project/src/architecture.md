# Архитектура и проектирование Project

Project владеет составом самостоятельных Repo и общим замыслом их совместной
работы. Имя берётся из package.json, состав Repo — из .gitmodules, версии —
из gitlinks. Самостоятельные Repo не вкладываются друг в друга. Дерево Project
сохраняется в его meta/data/tree.json; это восстановимые данные, а не источник
предметных правил Repo и его частей.

Проектирование связывает замысел с устройством системы: помогает выявить предметы,
установить их ответственность и отношения, выразить возможности и проверить
выбранное решение. Общие принципы задают Основания,
устройство ответственности — предметная архитектура.

Общий ход проектирования принадлежит Project. Размещение частей и направление
зависимостей раскрываются в методике Repo.
