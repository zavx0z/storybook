# Чтение спецификации владельца

[readSpec](./index.ts) находит непосредственную директорию `spec` и возвращает
полный отчёт её сценария. Отсутствие директории и отсутствие сценария различаются.
[Исполняемый пример](./spec/scenario.spec.ts) проверяет размещение спецификаций
у репозитория, пакета, категории и сущности.

Руководство получает подготовленный результат и извлекает из него
[руководство](../guide/README.md); Web использует полный отчёт
для просмотра и выполнения выбранного варианта.
