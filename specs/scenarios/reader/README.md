# Полный отчёт сценария

[readScenario](./index.ts) читает исходник, выполняет настоящий Bun Test, сохраняет
историю вызовов, данные проверок, потоки вывода, JUnit и подготовленный preview.
Для публичного default-класса preview сохраняет один прямой `new` и исход
конструирования из того же запуска.
Правила оформления применяет [валидатор сценария](./validation/index.ts).
Это технический источник для сборки, сервера, приложения и MCP. Функции
Руководство получает готовый отчёт и извлекает из него [примеры написания](../README.md).

Детали чтения и трассировки сохранены в [заметках](./meta/notes/reading.md),
[исполняемый пример](./spec/scenario.spec.ts) показывает полный отчёт, а
[проверки](./test/read-scenario.test.ts) подтверждают форму данных. Содержимое
отчёта не становится автоматически текстом руководства.
