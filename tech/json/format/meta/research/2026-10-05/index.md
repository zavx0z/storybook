# Стоимость форматирования большого служебного документа

[Три последовательных вызова](formatter.json): синтетический JSON 534 919 байт,
13 000 элементов со строками и escaped переносами; полный результат 599 931 байт.
Форматирование заняло 25,1 / 24,3 / 16,5 мс. Это Bun на машине разработки,
без CodeEditor, semantic DOM, GPU и принудительной GC. Снимки RSS не являются
пиком или измерением удерживаемой памяти документа.

Потребитель форматирует только раскрытые данные и переиспользует результат для
неизменного source. Отдельно проверяются стоимость токенизации, создание строк
редактора и живая страница; эти цифры их не описывают.
