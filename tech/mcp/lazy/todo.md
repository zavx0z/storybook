# Предложения по улучшению MCP Lazy

## Наблюдаемое обновление каталога инструментов

- [ ] Проверить доставку изменения схемы до клиента и локализовать причину устаревшего описания.

**Основание.** При вызове `storybook_rebuild_web` 4 октября 2026 года доступное
агенту описание содержало `live`, но исполнение отвергало его как неизвестный
аргумент. В текущем [App MCP](../../../app/mcp/src/server.ts) инструмент уже
описан как автоматически публикующий результат, а его
[схема](../../../app/mcp/src/schemas.ts) — пустой строгий объект. Дублирование
схем в этих исходниках не установлено; причина устаревания клиентского описания
остаётся открытой.

**Почему здесь.** [Lazy](index.ts) обслуживает стабильное соединение и получает
актуальные схемы и handlers из worker. [Наблюдение исходников](src/notifications.ts)
уже отправляет `notifications/tools/list_changed`. Поэтому новый механизм
инвалидации не нужен. [Тест обновления схемы](test/schema-refresh.test.ts)
явно вызывает `listTools` с `cacheMode: "refresh"` и не доказывает, что реальный
клиент сам перечитал каталог после уведомления.

**Предложение.** Дополнить проверку цепочки «изменение исходника → уведомление →
перечитывание каталога клиентом → вызов по новой схеме» на том же соединении.
Сделать диагностируемыми отправку уведомления и последующее получение `tools/list`,
не раскрывая секреты или содержимое пользовательских вызовов. Проверить связь
с реальной точкой запуска и `watchRoot`. Если сервер отправляет актуальные данные,
а хост удерживает прежнее описание, зафиксировать ограничение клиента отдельно;
не добавлять устаревшие аргументы в App MCP ради совместимости с его кешем.

**Проверка готовности.** Тестовый клиент после уведомления автоматически получает
новые description и inputSchema, вызывает обновлённый handler и не требует
перезапуска transport. Клиент, не перечитывающий каталог, различим в диагностике.
Сценарий изменения транзитивной зависимости также проходит, завершение соединения
освобождает watcher. Сохраняются существующие проверки
[native connection](test/schema-refresh.test.ts) и [stdio](test/stdio.test.ts).
