# Валидатор

Валидатор запускает существующие тесты для выбранного пакета, сущности
или спецификации и преобразует результат Bun в единый отчёт.
Требования и файловые примеры остаются в Archetypes.

Корневая функция `validate` последовательно вызывает `runTests` и
`transformReport`. Первая возвращает полный stdout, stderr и JUnit.
Вторая получает этот результат и возвращает статусы, сводку и сообщения
каждой проверки, сохраняя исходный вывод.

Входной путь и имя переменной окружения задаются явно. Валидатор не определяет
правильность структуры самостоятельно: это делают выбранные существующие тесты.
Поиск директории Spec выполняется отдельно и не запускает валидатор.

Проверки валидатора используют исходники и фикстуры Archetypes по существующим
путям. Они проверяют запуск и преобразование отчёта, не копируя правила.

Фильтр имён передаётся Bun. Нулевой выбор, который Bun завершает ненулевым кодом,
даёт `error`; успешный запуск без выполненных проверок — `empty`.
В JUnit Bun относит отфильтрованные тесты к skipped; отчёт сохраняет эту семантику.
Отсутствующий или некорректный JUnit даёт `error`.
Подключение этого этапа к автоматической сборке и MCP пока не выполнено.
