# Окно журнала MCP

Окно позволяет проверить обращения агента и самостоятельно увидеть ответ MCP
для открытого раздела Storybook. Переключатель выбирает один из двух режимов.

«Вызовы агента» показывает историю настоящих обращений: инструмент, параметры,
полный ответ и состояние выполнения. Ответ показывается одним
форматированным JSON с подсветкой, без извлечения полей или изменения данных.
Человек и агент видят один ответ; исходная запись журнала остаётся неизменной. «Текущий адрес → MCP» определяет владельца
открытой страницы и показывает его запрос `storybook` вместе с публичным ответом.
При смене адреса ответ обновляется; кнопка «Обновить ответ» повторяет чтение
того же адреса. Закрытое окно не выполняет запросы.

Браузер сохраняет положение, размер, открытое или закрытое состояние,
свёрнутость и выбранный режим окна. После перезагрузки эти настройки
восстанавливаются. Настройки общие для страниц Storybook на одном origin;
содержимое запросов и ответов в хранилище не записывается.

Источник второго режима — адрес страницы. Общий каталог определяет её владельца;
запрос использует path из общего навигационного контракта; подпись показывает
точный публичный адрес без параметров интерфейса. На корневой странице показывается независимый Storybook MCP.
Прямой MCP-вызов с параметрами отклоняется по
[контракту адресации](../../mcp/address/README.md). Страница вне каталога
показывает ошибку определения владельца без выдуманного MCP-вызова.
Сервер использует тот же обработчик и ту же очистку ответа, что и MCP. Эти чтения не попадают
в историю вызовов агента и не повторяют нажатия в интерфейсе.
